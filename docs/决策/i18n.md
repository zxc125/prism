# i18n 决策

> 官网 `site/` 中英双语落地（P11 stage 9 决策，P12 实现）的锁定决策。实现流水账见 [docs/阶段路径/P12-官网i18n.md](../阶段路径/P12-官网i18n.md)。

## 范围决策

- **仅官网 `site/` 双语**，全节一次到位（12 节 + nav + footer 全部接 `t()`）。
- **console `src/` 不在本阶段**，留 P12.x。

## 技术路线决策

- **自建轻量 composable，不引 vue-i18n**：`useLang.ts` 模块级 `useLocalStorage('prism:lang')` 单例 + `t(path)` 点分取值 + 缺省回退 zh-CN + `toggle()` + 同步 `<html lang>` + 运行时 patch `document.title`/`meta description`。借 `@vueuse/core` 的 `useLocalStorage`。
- **字典按 section 命名空间嵌套**（`zh-CN.json`/`en.json`）：meta/nav/hero/pain/manifesto/capabilities/multiwindow/diagnosis/loop/deploy/compare/architecture/quickstart/footer。
- **数据数组用 `computed(() => [...])` 包裹**响应语言切换；非文本字段（icon/accent/kind/dot/color）与技术值（命令/`per-session`/`Tauri 2`/`observer-server`/`HttpBackend`/`LoginGate`/时间码）保留原值不进字典。
- **带 HTML 结构的标题拆成可组合片段**（`h2_pre`/`h2_mid`/`h2_accent`/`h2_suf`），`<br/>` 和 `<span class="accent-*">` 留模板内，避免 v-html。
- **CompareSection 表格矩阵**用 `compare.rows.{dim}.cells.{n}` 嵌套 key（9 行 × 7 cells）。

## 边界决策

- **og/SEO 仅运行时双语**：`index.html`（title/og/twitter 全中文）+ `public/og-image.svg` + `manifest.webmanifest` 静态中文保持不动（爬虫不跑 JS，og 卡以静态 HTML 为准）。useLang 切换时 patch `document.title` + `meta description` 改善 tab 标题。

## 默认语言

- 默认 `<html lang="zh-CN">` + 中文 title（zh-CN 先行）。
- 语言切换器：`SiteNav.vue` 的 `.nav-actions` 加 `.lang-toggle` 按钮（中文态显「EN」、英文态显「中」），mono 风格 hair 边框。
