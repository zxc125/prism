# 一键打包上传 决策

> P24 需求评审（2026-11-02）拍板：外部观测应用（Tauri Local 落盘 / web 离线录制）内手动一键把本地已录会话批量上传到观测端。这是 P16 遗留的「真需求出现再议」（[外部应用本地落盘.md:32](外部应用本地落盘.md)）的手动腿兑现。方案见 [一键打包上传（方案）](../架构/一键打包上传（方案）.md)，实现流水账见 [P24-一键打包上传](../阶段路径/P24-一键打包上传.md)。

## 归属决策

- **归属**：立新 P24 走 /cycle。命中升格准则两条：**跨阶段**（sdk + observer-tauri + observer-server + examples + site/docs 五处）+ **改对外 API**（sdk/observer-tauri 新增公开导出）。先例同 [导出to-file变体.md](导出to-file变体.md)（仅一条新命令即升格 P18）。

## 范围决策

- **主场景**：Tauri Local 模式落盘应用 + web 离线录制应用。Remote 模式不做（数据已实时在观测端，插件 `ensure_local` 亦拒绝 list/export）；console 自身同机不做（本地导入闭环已通）。
- **触发形态**：手动单次触发。自动/定时上传维持 P16 non-goal，本 P 不重开自动钩子。
- **不脱敏**：upload 链路不做默认 redact，upload API 不带 redact 参数。责任边界：脱敏归接收端策略（多租户 import 强制 `redact_bundle`，单租户现状即透传）+ 需要脱敏的宿主自行走 `export(id, redactOpts)` → `uploadBundle` 组合（可选 opt-in 保留）。对离线方案 B4「上云前必经 scrub」的措辞张力，以本决策收口：客户端默认不脱敏。
- **接受重复**：不做客户端去重比对、不做服务端幂等键。import 换新 id 语义（bundle-规范.md「导入时 id 由接收方重新分配」）维持，同一会话重复上传 = 观测端多份独立会话，已知且接受。

## 技术路线决策

- **前端编排（方案 A）**：上传执行器住前端 JS（与 HttpSink 先例一致）；插件 Rust 侧零改动（零 HTTP 依赖、零权限变更，复用 `list_sessions`/`export_session` 只读命令），不触碰「写命令面不进插件」决策。
- **端点与契约复用**：复用 `POST /sessions/import` 现成端点；prism-session v1 契约不动（P22 已有「version bump 不做」先例）。
- **请求侧 gzip 带能力协商**：server 加 `Content-Encoding: gzip` 请求解压——这是**传输层**能力，与 P9 排除项「bundle 内嵌 gzip / version 2」不同层，显式区隔不视为重开。客户端经 `GET /whoami` 探测（新版 server 响应带 `requestGzip` 标记）决定是否压缩；老 server 一律明文，规避 `read_body` 非 UTF-8 静默 400。
- **批量 = 串行逐会话循环**：无批量端点、无多会话容器格式（bundle 契约单会话粒度是事实约束）；对齐 console batchDelete 串行范式，控内存峰值（server 单线程串行，并发上传会阻塞 `/ingest/*` 实时流）。
- **超大会话兜底**：不做上传前体积预检（需整串序列化，成本不划算）；兜底呈现为上传失败的错误文案引导 + 手册指引改走 `export_session_to_file` 人工路径（P18）。

## 边界决策

- **上传登记表不做**：逐会话回执 `{remoteId}` 展示即止，宿主侧持久化登记留未来。
- **demo 的 `?token=` URL 参数注入不照抄**：token 走 localStorage 配置 UI（URL 参数会进浏览器历史）。
- **console 接收端 API 不动，导入交互纳入**：接收端命令/端点已完备（import_session/import_session_path + 导入 tag），不加新命令；但 console「导入录制文件」现状零交互（单文件选择 + 一条成功消息），拖放/多选/逐文件进度回执的导入 UX 纳入本阶段（用户 2026-11-02 追加），impl 阶段按视觉约定先走 `/frontend-design`。
- **文档落差随本 P 收敛**：site/docs/web.md:96（宣称「下载或上传」）、observer-sdk `recordOffline` docstring 同款失实、site/docs/concepts.md:81（三条→四条拓扑）、[被观测侧（采集）](../架构/被观测侧（采集）.md) Sink 表同步。

## 默认值 / 取值

- `uploadSessions` 缺省 ids = 全部本地会话（`listSessions()`）：一键语义；接受重复故重复点击安全（产生重复会话但不损坏数据）。
- SDK `gzip` 默认 `false`；observer-tauri `gzip` 默认 `"auto"`（批量前探测一次 /whoami）。
- 失败策略：单会话上传失败不中断批量，聚合逐会话结果数组返回。
