# 外部应用本地落盘 决策

> P16 spec 阶段拍板：外部 Tauri 应用可选「本地落盘」通路（插件 Local 模式从「console 自录专属」泛化为「任意宿主 opt-in」），承接 [离线导出与云端部署（方案）](../架构/离线导出与云端部署（方案）.md) B11 悬空项。实现流水账见 [docs/阶段路径/P16-外部应用本地落盘.md](../阶段路径/P16-外部应用本地落盘.md)。

## 范围决策

- **外部 Tauri 应用数据通路 = 双通路 opt-in**：默认 Remote（HTTP -> console），可选 Local（Rust 落盘到外部应用**自己的** `appDataDir/recordings/`）。HTTP 实时上报仍是主路径（闭环最短）；本地落盘服务「数据 own 在被观测方」的本地优先拓扑，不让被观测方被迫连 console。
- **回放/诊断闭环仍收敛到 console**：外部本地落盘的会话经 bundle 导出 -> console 导入回放，外部应用不内嵌回放 UI。锁定决策 #3 不变。
- **bundle 契约不动**：version 1 纯 JSON 直接复用，仅新增「第四条投递路径：外部 Tauri 应用本地落盘 + 导出」。P9 已锁 version 1，bundle 格式天然覆盖此场景。

## 技术路线决策

- **JS 驱动复用 `initTauri()` 加 `mode` 选项**（`"remote" | "local"`），不另起新入口/新包。同一套多窗口事件协议（`recording-session`/`segment` 广播），Remote/Local 差别仅在 Sink 与 sessionId 来源；新入口会造成双驱动漂移。
- **TauriSink 放 `@prism-obs/observer-tauri` 包，不进 observer-sdk**。observer-sdk 是纯 web 包（peer 仅 rrweb），引入 `@tauri-apps/api` 会污染 web-only 消费方；observer-tauri 本就依赖 `@tauri-apps/api`，语义即「外部 Tauri 应用 JS 驱动」。架构分层图预留的「[未来] TauriLocalSink」名位由此落定：**不新造类名，Local 模式复用 TauriSink**（协议同 invoke `plugin:observer|*`）。
- **source/appId 注入点 = `ObserverConfig`（Rust 侧，`init_with` 时声明）**，不改 `start_session` 命令签名。会话元数据属部署拓扑（「这个应用是谁」），归宿主装配时声明；命令加参会令 autoStart 与非 autoStart 路径出现两套元数据来源。
- **插件暴露 `list_sessions` / `export_session` 两个只读命令**（Local 模式限定，Remote 下返回错误）。闭环所需最小命令面；写命令面不进插件。
- **console 自身 `TauriSink` 改为从 `@prism-obs/observer-tauri` re-export**，删本地实现。两份实现必然漂移；console 是 Tauri app 前端不发布 npm，无依赖方向顾虑。

## 边界决策

- **锁定决策 #2 表述显式扩展（非推翻）**：「统一走 HTTP sink -> console 本地 server」→「外部应用默认 HTTP 上报，opt-in 本地落盘（bundle 契约不变）」。与 P8 放宽 #1（自托管 ≠ SaaS RUM）同类：显式 opt-in 放宽，有先例可循。
- **不做 `delete_session` / annotations 写命令进插件**：删数据是危险操作；宿主应用自行管理自己 `recordings/` 目录，console 的删除/编辑能力不外放。

## 默认值 / 取值

- `initTauri` `mode` 默认 `"remote"`：现网 API 完全兼容，存量外部应用零改动。
- `ObserverConfig::source` 默认 `"self"`：console 行为零变化；外部应用建议 `"tauri"` + `appId`（与 web ingest 会话字段对齐，console 来源色直接生效）。
- 版本目标：`tauri-plugin-observer` 0.1.0 -> 0.2.0（additive minor）；`@prism-obs/observer-tauri` 0.2.0 -> 0.3.0（additive minor）；`@prism-obs/observer-sdk` 不动不发。流程遵循 [npm-crates发布](npm-crates发布.md)。
