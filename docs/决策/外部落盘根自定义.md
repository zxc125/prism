# 外部落盘根自定义 决策

> P20（2026-09-17 评审定稿）：`tauri-plugin-observer` Local 模式落盘根可配置（`dir_base`/`dir_name`），外部应用（bond-sat）可把会话落盘指到安装目录。上位外部输入：bond-sat 侧提案《observer-plugin-0.3.1-落盘根自定义提案》（2026-09-17，其仓库 docs/observer-recording/bugs/）。实现流水账见 [docs/阶段路径/P20-外部落盘根自定义.md](../阶段路径/P20-外部落盘根自定义.md)。

## 范围决策

- **能力边界**：`ObserverConfig` 新增 `dir_base: DirBase`（枚举 `AppData` | `ResourceDir`）+ `dir_name: String` 两可选字段，仅 Local 模式实际解析。理由：bond-sat 要求落盘随安装目录（Windows 终端运维口径：数据随安装目录、便于现场收集）；限定 Tauri 标准基目录、不收任意绝对路径，避免宿主传非法路径的边界（资源目录由系统/安装器保证存在）。
- **版本 0.4.0 minor，不采提案的 0.3.1 patch**：本仓锁定惯例「0.x minor = 兼容新增，patch 仅限公开 API 不变的执行模型变更」（[段控制上收与性能加固](段控制上收与性能加固.md)、P17 D6、P18 D7、[npm-crates发布](npm-crates发布.md) 版本轨迹）。本次新增公开 API（`DirBase`/`dir_base`/`dir_name`/`recordings_root_with()`）→ minor。bond-sat 提案已声明「以评审定稿为准回改」，其依赖锁定随通知回改 0.4.0。

## 技术路线决策

- **注入点 = `ObserverConfig`（Rust 装配时声明）**：与 source/appId 同一条理由——落盘根属部署拓扑，归宿主装配时声明（援引 [外部应用本地落盘](外部应用本地落盘.md) D3 先例）。
- **API 形态 = 新增 `recordings_root_with(app, &cfg)`，原 `recordings_root(app)` 委托保留**：console 宿主 `src-tauri/src/lib.rs` 实测 13 处直接调用（提案称 7+），签名不可变更；console 13 处保持原函数不动，插件 crate 内 4 处（`commands.rs` :66/:271/:291/:326）切 `_with`。
- **解析时机 = 惰性逐次解析，不缓存**：调用频率极低（start_session 一次 / list·export 偶发），无性能考量；不缓存免 `Session::new` 引入 `AppHandle` 签名变更，测试面最小。`Session.dir` 仍为会话级缓存（`start_session` 解析一次），config 进程期固定，语义不变。

## 边界决策

- **不做历史数据迁移**：宿主切根后，旧根（`appDataDir/recordings`）下的会话从 `list_sessions`/`export` 中消失（数据不删，仅不可见，各自独立根目录）；手册与本文档双重注明。`ObserverConfig` 进程期固定（`init_with` 装配，无热切换），不存在「会话进行中换根」。
- **不提供任意绝对路径**：限定 Tauri 标准基目录，理由见范围决策。
- **JS 侧零改动**：`ObserverConfig` 仅 Rust 侧（无 TS 镜像类型，`initTauri(opts)` 不透传 config，已核实），npm 两包不发版。
- **bundle 契约不动**：bundle 为纯内容格式、无任何文件系统路径字段（[bundle-规范](../架构/bundle-规范.md)），改根不触碰契约、无 version bump 依据。
- **对《外部应用本地落盘》决策的放宽声明（扩展而非推翻）**：该决策将 Local 落盘位置锁定表述为「宿主**自己的** `appDataDir/recordings/`」；本决策将其放宽为「宿主选定的 `<dir_base>/<dir_name>`（默认值 = 原表述）」。显式 opt-in 放宽，默认行为逐字节不变——同 P8 放宽决策 #1、P16 放宽决策 #2 的先例范式。

## 默认值 / 取值

- `dir_base` = `AppData`（`"appData"`）：现状行为，存量宿主零 diff。
- `dir_name` = `"recordings"`：现状行为。
- serde 命名：`DirBase` 用 `camelCase`（`"appData"`/`"resourceDir"`），与 `ObserverConfig` 既有 `rename_all = "camelCase"` 风格一致。
- `DirBase` derive 对齐 `Mode`：`Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize` + `Default`（`#[default] AppData`）。

## 未做（留后续）

- 更多基目录枚举值（Tauri `BaseDirectory` 其余项，如 Desktop/Documents）：无需求方；枚举 + serde camelCase 向后兼容，按需加值即可。
- 落盘根的 UI 展示/设置页入口：console 设置页不展示落盘路径（已核实零命中），无需求。
- 跨根会话合并视图（同时列多个历史根）：无需求方；切根是低频一次性运维动作。
