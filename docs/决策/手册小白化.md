# 手册小白化 决策

> 2026-09-08，/cycle 需求评审产出。背景：官方文档站（site/，P13 Phase 1 产物）5 篇手册按「有经验开发者」口径写成，零基础读者无法仅靠手册跑通全链路。需求：手册加深到小白可独立上手。实现流水账见 [docs/阶段路径/P15-手册小白化.md](../阶段路径/P15-手册小白化.md)。

## 范围决策

- **目标读者口径**：从「有经验开发者」改为「零基础可跟做」——小白按 quickstart 从零操作即可跑通「起 console → 被测应用接入 → console 看到会话回放」，不依赖手册外资料。<理由>用户明确需求；验收据此可测化（全链路无歧义步骤）。
- **改动面**：只动 `site/docs/`（zh 5 页 + en 5 页）与 `examples/*/README.md`，不动任何产品代码（src/、src-tauri/、crates/、packages/）。<理由>纯文档深化，与 P13/P14 的代码产出正交。
- **页面结构**：维持现有 5 页（快速开始/核心概念/Web SDK/Tauri Plugin/私有化部署），不加新页面。<理由>信息架构已合理，缺的是深度与跟做性，不是分类。

## 技术路线决策

- **页内统一模板**：每页遵循「本页你将完成什么 → 前置条件 → 分步操作（可复制命令/代码 + 每步验证点）→ 故障排查 → 下一步」。<理由>小白断点集中在「缺前置条件、缺验证点、出错无解」，模板化一次性消除三类断点。
- **手册与 examples 互为完整链路**：给 `examples/web-demo`、`examples/tauri-demo` 补 README（是什么/怎么跑/演示参数），手册引用它们作为「完整可跑示例工程」。<理由>P13 定了 examples 是代码片段唯一可信源，但两 demo 零自述，引用价值打折。
- **录制档位按三档预设语义写**：recording 章节只写 `full/balanced/minimal` 三档 + `domBlocks` 免录区，不引导用户裸调 `RecordTuning`。<理由>遵循 [录制事件量控](录制事件量控.md) 决策「预设制而非裸暴露」，裸调口子留 P.x。
- **版本锚定**：手册标注适用版本 observer-sdk / observer-tauri **0.2.0**，后续 API 变更同步时更新此标注。<理由>本次漂移（recording 章节缺失）根因是文档无版本锚点，读者无从判断时效。

## 边界决策

- **deploy 获取口径**：`cargo install observer-server` 改为「源码构建（`cargo install --path`）为主路径」，删除对 crates.io 安装的引导。<理由>observer-server 不发布 crates.io 是 [npm-crates发布](npm-crates发布.md) 决策「未做」项，现手册教读者跑必失败命令，是已兑现的漂移。**不**顺手扩 scope 去发 crate。
- **en 手册同批加深**：zh 加深的同时 en 按同结构翻译跟进（en 可略简但章节结构一一对应），en 翻译质量打磨仍留「未做」。<理由>维持 P13 Phase 1 验收「zh 全量 + en 同结构」的形态承诺，避免 zh/en 差距不可控拉大。
- **P14 3.3 并入实施、账记原处**：web.md 的 recording 配置章节（P14 3.3 义务）随本 P 一并写掉，完成记录回写 P14 文档 3.3 行。<理由>3.3 只是本需求一小块；账记原处避免 P14 状态与事实脱节。

## 默认值 / 取值

- 文档版本基准 = 0.2.0：observer-sdk 与 observer-tauri 当前发布版本，手册所有签名/选项以此为准。
- 全链路验收场景 = 「clone 仓库 → 起 console → 跑 examples/web-demo → console 看到会话与回放」：与 P14 场景 6 实测基建（行情模拟页 + recording URL 参数）复用。
