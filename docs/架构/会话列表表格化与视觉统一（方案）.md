## 4. 技术方案

### 4.1 列定义（SessionList.vue）

| 列（左→右） | 字段 | 渲染 | 对齐现卡片 |
|---|---|---|---|
| 选择 | — | checkbox（表头全选含 indeterminate，作用于筛选全集）；批量删除入口 | 新增（D9，spec 补录） |
| 来源 | `source` | StatusDot 色点 + mono 标签（本机/web/tauri） | 保留签名元素 |
| 开始时间 | `startedAt` | mono `MM/DD HH:MM` | 同 |
| 时长 | `endedAt` | 已结束 → mono `mm:ss`；未结束 → 「未结束」琥珀徽标 | 语义修复 |
| 名称 / ID | `name \|\| id` | mono；named 高亮；title 双值；超宽 ellipsis（虚拟表格固定列宽需裁剪策略） | 同 |
| appId | `appId` | mono 小字，无值整格空 | 新增（D6） |
| 标记 | `importedAt` | 「导入」tag | 同 |
| 操作 | — | 回放按钮 + ⋯下拉（编辑/导出/删除） | 同 |

排序沿用 `list_sessions` 返回序（startedAt 倒序，Rust 侧已排），前端不重排。

### 4.2 时长语义（format.ts）

```ts
/** 会话时长：仅已结束会话有值；未结束返回 null（展示层出「未结束」徽标，不再 now 兜底）。 */
export function sessionDur(s: SessionMeta): string | null {
  if (!s.endedAt) return null;
  return fmtDur(s.endedAt - s.startedAt);
}
export const isSessionOpen = (s: SessionMeta): boolean => !s.endedAt;
```

### 4.3 字体统一（theme.css）

```css
:root:root {
  --el-font-family: var(--font-sans); /* EP 组件回接 token，双 specificity 压过 EP 内置 */
}
```

走查清单：el-input/el-select/el-dialog/el-dropdown/el-table-v2/el-message/el-tag 全组件实页面核对 + 自建组件抽检；table-v2 深色变量（`--el-table-v2-*` 系）按需补齐并移除 v1 无主 nudge。

### 4.4 table-v2 样式引入（impl 首步实测）

ElementPlusResolver 对 table-v2 的样式解析待验证：缺则显式引入 `element-plus/es/components/table-v2/style/css`（或 `table-v2.css` 局部文件）；AutoResizer/列渲染子组件同验证。
