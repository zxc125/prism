## 3. 设计决策 ★

见 [决策文档](../决策/会话用户归属与会话级启停.md) D1-D8。对 bond-sat 提案的两处修正：

- **D2 stop 路径**：提案的 `session_meta_payload` 第 6 参方案需在 `Session` 态加 `extra_meta` 字段（start 存、stop 复用），隐含前提未写明，且维持「状态重建文件」模型。本方案改 read-modify-write：`stop_session` 只 merge `{"endedAt"}`，任意宿主字段天然保留，并解除 stop 对 `source`/`app_id`/`started_at` 状态的依赖。现有测试 `stop_overwrite_keeps_app_id` 的防护对象（重建覆盖）随之消失，测试改造见 §4.1。
- **Remote 会话重绑**：提案称 Remote `startSession` = `httpSink.startSession + bind_session 广播`，但现有 `sessionBound` 一次性守卫（index.ts:173）使第二会话的 bind 广播被主窗/子窗全部忽略，段事件会继续上报已 endSession 的旧 sessionId。必须配合重置逻辑（§4.2）。

## 4. 技术方案

### 4.1 插件 commands.rs

```rust
/// start_session 增参（Option 缺省 None = 存量零 diff）：
pub fn start_session<R: Runtime>(
    app: AppHandle<R>,
    state: State<'_, SessionState>,
    meta: Option<serde_json::Value>,
) -> Result<String, String>
```

- 纯函数 `merged_meta(base: Value, extra: Option<&Value>) -> Value`：extra 非 object 报 Err（防呆）；逐键 merge 后**再插基础键**（id/source/appId/startedAt[/endedAt]，D3 保留键保护）。Local 分支写 session.json 时经此组装。
- `stop_session` Local 分支：`finalize_session` 后改调 `merge_session_meta(&dir.join("session.json"), &json!({"endedAt": ended_at}))`，删除重建路径与 source/app_id/started_at 解构（状态字段保留不删，仅停用）。`session.json` 由 start 必建，缺失 merge 失败 best-effort（与 finalize 同级容忍）。
- 测试改造：`stop_overwrite_keeps_app_id` 删（防护对象消失）；新增 `merged_meta_merges_user` / `merged_meta_base_keys_win` / `merged_meta_rejects_non_object`。storage 层 roundtrip 已有 `export_import_roundtrip`，/regress 时补 user 断言。

> **impl 修正（2026-09-18，/regress 两轮 subagent 复核后定稿）**：① stop 写路径——`finalize_session`（observer-storage storage.rs:210）本身即 read-modify-write 只补 endedAt，直用之即可，无需再叠 `merge_session_meta`（上文 §1/本节与 storage.rs re-export 计划随之免除）；语义与 D2 完全一致，少一轮文件读写；顺带根除 console name/note/tags 被 stop 整文件重建冲掉的存量问题。② `HttpSink.endSession` 改「进入即捕获并解绑」+ `flush(sid)` 显式带参（§4.2 未预见的配套改动）：缓解 Remote 幂等 `startSession` 的 end 竞态（残留两类低概率错配窗口，留观察，1.7 实测把关）。细节见 [P22 文档陷阱段](../阶段路径/P22-会话用户归属与会话级启停.md)。

### 4.2 observer-tauri index.ts

```ts
// TauriController 增：
async startSession(meta?: Partial<SessionMeta>) {
  // 幂等收口：已活跃先 stop_session（广播 active:false 驱动各窗停段 + remote 主窗 endSession）
  if (await invoke<boolean>("plugin:observer|is_recording_active")) {
    await invoke("plugin:observer|stop_session");
  }
  if (local) {
    await invoke("plugin:observer|start_session", { meta });   // Rust 建目录/写 meta/广播
  } else {
    const sid = await sink.startSession(meta);                  // HttpSink merge 实参上报
    httpSink?.useSessionId(sid);
    sessionBound = true;
    await invoke("plugin:observer|bind_session", { sessionId: sid });  // 广播子窗
  }
},
async stopSession() {
  // 双模统一：Remote 的 stop_session 清态+广播（主窗 endSession 由既有监听驱动）；
  // Local 写 endedAt。不 unlisten、不 destroy——进程内可再次 startSession。
  await invoke("plugin:observer|stop_session");
},
```

- **重绑坑修复**：`recording-session` 监听的 `!active` 分支补 `sessionBound = false;`——第二会话的 `bind_session` 广播才能被各窗重新消费。
- autoStart 路径、段门控（`gating: "manual"` 只置态不开段）、`stop()` 语义全部不动；存量宿主零 diff。
