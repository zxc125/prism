# 分析侧（平台布局结构、功能）

本文档描述「前端观测平台」的分析端（console）：作为本地优先的分析台，它接收采集端上报的数据、存储、回放、诊断、导出。

## 定位

console = 现有 Tauri App 演进。本地优先（决策 1），零云依赖，单用户。它有**双重身份**：

1. **自录者**（self-obs）：录制自己的窗口（现有能力），走 `TauriSink`，进程内、零序列化。
2. **接收端**：起本地 HTTP server，接收外部 Web SDK / Tauri Plugin 上报，走 `HttpSink` -> 同一套存储函数。

两条路径复用同一存储层与回放层，self-obs 天然成为外部采集器的第一个验证场景。

## 存储层（复用，不改格式）

沿用现有布局，外部数据落进同一结构，回放侧无感：

```
recordings/<sessionId>/
  session.json              # { id, startedAt, endedAt?, appId, env, release, context }
  windows.jsonl             # 窗口生命周期
  segments/<label>#<n>.jsonl  # 交错事件流（DOM + error/console/network type:6）
  annotations.jsonl         # 用户标注（P6，session 级）
```

扩展点：`session.json` 增加 `appId`/`env`/`release`/`context` 字段；新增 `annotations.jsonl`（P6）。segment 文件因交错事件模型，**格式不变**，只是多了 type:6 事件行。

存储函数（现 `begin_segment`/`append_events`/`append_lifecycle` 等命令的落盘逻辑）从 `invoke` 调用者中抽出，`TauriSink` 与 HTTP handler 共用。

## 本地 HTTP server（接收端）

console 启动时在 localhost 起一个 HTTP server（端口可配，默认避让 Vite 1420），暴露 `/ingest/*`（见 [被观测侧](./被观测侧（采集）.md)）。handler 调用同一套存储函数落盘。

约束：
- 仅监听 `127.0.0.1`（本地优先，不对外）。
- 简单鉴权（本地 token），避免同机其他进程误投。
- 大体请求流式写盘，不在内存堆积。

## 布局结构

整体从「录制器 + 播放器」重做为「观测站」。视觉语言（琥珀/牛血/等宽/控制台）保留；改的是信息架构与布局。详见 [P1-分析端页面改造](../阶段路径/P1-分析端页面改造.md)。

### MainView = 会话观测台
- **左 rail = 源监控机架（source rack）**：平台的输入 bay，每来源一条通道。本机通道承袭 REC 按钮的 DNA（环形 + 录制中脉冲），web 通道按 server 监听状态点亮（P4 已落地，显示接入点与 web 会话数），tauri 为「待接入」暗通道（P5 落地点亮）。下方：server 接收状态、设置入口。
- **右内容区 = 会话浏览器（hero）**：来源过滤 chip（全部/本机/web/tauri）+ 搜索 + 富行（来源色点·时间·时长·错误数·窗口数·ID·回放/更多）。
- **签名**：源监控机架--「一个源 -> 多源」的平台转向浓缩在一个元素。

### PlayerView = 诊断工作台
- **左主区**：spotlight 回放网格（现有，多窗口对齐--核心论点，不动）。
- **右侧诊断栏**（P1 新增，可折叠）：统一的**信号流**（console/network/error 混排一条时间流 + 来源过滤），不用三 tab（避免 DevTools 泛模板，且把交错事件模型在 UI 显形）。行带等宽时间码，随播放头高亮，点击 seek。
- **顶部时间轴**（现有色带 + focus 标记 + playhead）：叠加 error 红标点（`--oxblood`）。
- 视觉方案走 `/frontend-design` skill。

### SettingsView = 安静配置
- 新增：HTTP server（端口/token/开关）、采集开关（哪些信号、network body 是否记）、保留策略。

## 来源色（复用 lane 调色板）

每个来源在全 UI 有稳定身份色：本机=`--amber`、web=`--lane-7 #6FA8DC`、tauri=`--lane-5 #8AB36A`。用于源机架通道、会话行圆点、过滤 chip 激活态。不引新色值。
