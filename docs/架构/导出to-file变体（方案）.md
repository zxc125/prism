## 3. 设计决策 ★

| # | 决策点 | 选择 | 理由 |
|---|---|---|---|
| D1 | 命令签名 | `export_session_to_file(app, state, session_id, path) -> Result<u64, String>`（返回写入字节数） | 宿主可提示成功；`()` 与 u64 均 additive，u64 零成本更有用 |
| D2 | 门禁 | `ensure_local` + `validate_session_id`，与 `export_session` 完全同款 | Remote 数据不在本机（P16 D6）；穿越防护 P7 复用 |
| D3 | 执行模型 | `async fn` + `tauri::async_runtime::spawn_blocking` 包住 build→serialize→write | 秒级操作不占 async worker；区别于 P17 D3 属性（既有命令最小改动取舍，此处无包袱） |
| D4 | 落盘方式 | 同级 `.tmp` 写入 + `std::fs::rename` | P7 导入侧原子写惯例；防残缺 bundle |
| D5 | D5 决策关系 | **扩展**——宿主仍决定落盘目标，插件代执行 IO | 不推翻 P16 D5 原意；论证见 [决策文档](../决策/导出to-file变体.md) |
| D6 | 权限 | `allow-export-session-to-file` 入 `observer:default` | 与 export-session 同数据面，无能力升级；宿主零额外配置 |
| D7 | 发版 | crates 0.3.0 + npm 0.5.0（observer-storage 不动） | additive minor 先例（P14/P16/P17） |

## 4. 命令实现 ★

### 4.1 Rust 侧（commands.rs 追加）

```rust
/// Local 模式：导出会话 bundle 并由插件直接写盘（P18，D5 扩展——落盘目标仍由宿主传
/// `path` 决定，插件代执行大 JSON 序列化与文件写入，避开宿主 JS 主线程与大载荷 IPC）。
/// 返回写入字节数。`path` 任意（导出目标天然任意，通常经 save 对话框取得）；
/// session_id 仍走 P7 穿越防护。`.tmp` + rename 原子写（P7 惯例）。
#[tauri::command(async)]
pub async fn export_session_to_file<R: Runtime>(
    app: AppHandle<R>,
    state: State<'_, SessionState>,
    session_id: String,
    path: String,
) -> Result<u64, String> {
    ensure_local(&state.lock().map_err(|e| e.to_string())?.config)?;
    if !validate_session_id(&session_id) {
        return Err(format!("invalid session id: {session_id}"));
    }
    let dir = recordings_root(&app).join(&session_id);
    tauri::async_runtime::spawn_blocking(move || -> Result<u64, String> {
        let bundle = build_export_bundle(&dir)?;
        let json = serde_json::to_string(&bundle).map_err(|e| e.to_string())?;
        let tmp = format!("{path}.tmp");
        std::fs::write(&tmp, json.as_bytes()).map_err(|e| e.to_string())?;
        std::fs::rename(&tmp, &path).map_err(|e| e.to_string())?;
        Ok(json.len() as u64)
    })
    .await
    .map_err(|e| e.to_string())?
}
```

注意：`State` 不能跨 `spawn_blocking` move——门禁与路径拼装在闭包外完成（如上）；`state.lock()` 在 await 前释放（语句级作用域，无跨 await 持锁）。

### 4.2 权限（default.toml + build.rs 自动生成）

```toml
# permissions/default.toml permissions 集追加
"allow-export-session-to-file",
```

build.rs 重新生成 `autogenerated/` + `schemas/schema.json`（随 `cargo build` 自动）。

### 4.3 TS 包装（packages/observer-tauri/src/index.ts）

```ts
// TauriController 接口追加
exportSessionToFile(sessionId: string, path: string): Promise<number>;

// 实现（与 exportSession 同款 Local 门禁）
async exportSessionToFile(sessionId: string, path: string) {
  if (!local) throw new Error("[observer-tauri] exportSessionToFile 仅 Local 模式可用");
  return invoke<number>("plugin:observer|export_session_to_file", { sessionId, path });
}
```

## 7. 不做什么（scope 纪律）★

- **console 前端不切 to-file** —— Blob 下载交互不变，切走需 dialog 插件；console 也命中②③但收益属另一交互形态，留独立小改。
- **不动 `export_session` 本体与 Remote 链路** —— additive 纪律。
- **不做 path 白名单/父目录校验** —— 决策文档「无实质能力升级」论证，导出目标天然任意。
