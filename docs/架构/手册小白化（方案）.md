> 官方文档站 5 篇手册按「零基础可跟做」标准加深的可落地方案。决策依据见 [P15-手册小白化.md](../阶段路径/P15-手册小白化.md) 的「设计决策」表与 [手册小白化](../决策/手册小白化.md)，本文不重复论证。

## 1. 总览 ★

把 site/ 文档站 5 篇手册（zh/en ×5）从「API 简述式」加深为「零基础分步跟做式」，并补齐 P14 3.3 的 recording 章节义务。改动块图如下：

```
site/docs/*.md        : zh 5 页全面重写加深（+recording 章节 = P14 3.3）
site/en/docs/*.md     : en 5 页同结构跟进翻译
examples/web-demo     : 补 README（跑法 + ?sim/?profile/?block 演示参数说明）
examples/tauri-demo   : 补 README（跑法 + workspace 依赖说明）
```

非目标：API reference 全量、版本站、changelog（P13.x）；营销页 SSG（P13 Phase 2）；截图（本批不做，见 O1）；任何产品代码改动。

## 3. 设计决策 ★

| # | 决策点 | 选择 | 理由 |
|---|---|---|---|
| D1 | 页内结构模板 | 「你将完成什么 → 前置条件 → 分步（可复制+验证点）→ 故障排查 → 下一步」五段式，全部页统一 | 小白断点三类（缺前置/缺验证/出错无解）一次消除；结构统一降低 en 翻译失同步风险 |
| D2 | recording 章节形态 | `init({ recording: { profile, domBlocks } })` 三档行为差异表 + 「minimal 不降 mutation，请配免录区」警示框 | P14 3.3 义务 + [量控决策](../决策/录制事件量控.md) L19 明确要求的预期文案 |
| D3 | deploy 获取口径 | 主路径 `cargo install --path crates/observer-server`（源码），crates.io 安装删除 | observer-server 不发 crates.io 是既定「未做」项 |
| D4 | 前置条件粒度 | quickstart 列明 Node ≥18 / pnpm / Rust toolchain（tauri dev 形态才需要）/ 浏览器 | 小白跑不通的第一断点就是环境 |
| D5 | 概念解释深度 | concepts.md 用类比（DOM 快照 ≈ 逐帧「存结构」而非录屏「存像素」），不展开 rrweb 内部实现 | 小白要能建立心智模型，不是读论文 |
| D6 | 示例工程引用 | 手册每处「完整示例」链接指向 examples/*/README.md，README 给逐命令跑法 | 兑现「examples 为唯一可信源」并使其自解释 |

## 4. 各页内容方案

### 4.1 quickstart.md（重写）

1. **Prism 是什么**：3-5 句导引（录制浏览器/应用操作与诊断信号 → 本地 console 回放诊断），不展开架构。
2. **前置条件**（D4）：Node ≥18、pnpm、Rust toolchain（仅 tauri dev 形态）、现代浏览器。
3. **第 1 步起 console**：`pnpm install && pnpm tauri dev`（开发形态）/ 源码构建产物路径说明；**验证点**：主窗口出现。
4. **第 2 步装 SDK**：完整 `npm install @prism-obs/observer-sdk` + 最小 `init()` 代码块（对照 packages/observer-sdk/src/index.ts 真实签名）；**验证点**：Network 面板出现 `/ingest` 请求。
5. **第 3 步触发并查看**：给出可复制的触发代码（`throw` 或按钮），console 会话列表刷新路径指到具体设置页位置；**验证点**：会话卡片出现、点入可回放。
6. **故障排查**：端口占用 / 401 token / 列表为空三类。
7. **下一步**：链接 concepts/web/tauri。

### 4.2 concepts.md（加深）

- 会话/段/交错事件模型/来源/bundle 各节保留，前置新增「录制的是结构化 DOM 快照而非视频」类比（D5）；「多窗口」在 web 单 tab 语境下补一句铺垫；`lane-5` 改为通俗说法。

### 4.3 web.md（重写，含 P14 3.3）

- **安装** → **快速接入**（最小可跑）→ **`init()` 选项全集表**（appId/endpoint/token/env/release/label/signals/recording/meta，逐项类型+默认值+说明，对照 `InitOptions` 真实导出）→ **录制量控**（D2：三档差异表 + domBlocks 免录区 + minimal 警示框）→ **离线采集 `recordOffline()`**（含 OfflineController 方法表）→ **脱敏 `redact()`** → **诊断信号** → **背景色须知** → **框架集成**（补从零 Vite 项目链路 + SSR 提醒）→ **完整示例**链接 examples/web-demo/README.md。
- 版本锚定：页首标注「适用 @prism-obs/observer-sdk 0.2.x」。

### 4.4 tauri.md（加深）

- `initTauri()` 选项全集表（对照 `InitTauriOptions`：appId/endpoint/token/env/release/autoStart/signals/recording/meta）；capabilities 补文件位置（`src-tauri/capabilities/*.json`）+「每个窗口 label 必须列入，否则窗口无权限」醒目提示；hash 路由一段解释；上报地址热切解释 localStorage 机制；完整示例链接 examples/tauri-demo/README.md。

### 4.5 deploy.md（修正 + 加深）

- 获取口径改源码构建（D3）；「浏览器化」节开头明确「需先克隆本仓库并 `pnpm build`」使叙事自洽；tenants.json scrubbers 加 JSON 正则转义提示与正确/错误对照；新增 systemd 单元最小示例；SDK 侧对接节补指向 web/tauri 手册的链接。

### 4.6 en/docs/*.md（Phase B）

逐页同结构翻译跟进（章节标题一一对应，正文可略简）；版本锚定同步。

### 4.7 examples README

- web-demo/README.md：一句话定位（P14 场景 6 载体）→ `pnpm dev` → URL 参数表（`?sim` 行情模拟 / `?profile=full|balanced|minimal` / `?block=…` 免录区）。
- tauri-demo/README.md：定位（Remote 模式被观测 Tauri 应用）→ 前置（console 已起、workspace 内 `pnpm install`）→ `pnpm tauri dev` → 预期看到什么。
