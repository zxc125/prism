# 落盘保留期自动清理（最佳实践方案）

> P23 可落地方案。需求源：bond-sat 提案（2026-10-20 定稿）+ 本仓五路代码核对（2026-10-20）。决策依据见 [docs/决策/落盘保留期自动清理.md](../决策/落盘保留期自动清理.md)，本文不重复论证。

## 1. 总览 ★

把 P9 沉淀的 `observer-storage::retention` 能力接到 `tauri-plugin-observer` Local 落盘：storage 加保护名单变体 + 孤儿清理维度，插件加策略字段与周期清扫线程。改动块图：

```
crates/observer-storage        : retention.rs 加 enforce_retention_protect（protect + 孤儿维 + 删除纪律）；RetentionPolicy 加 orphan_max_age_days
plugins/tauri-plugin-observer  : config.rs 加 retention 字段；lib.rs re-export + setup 起清扫线程；README 同步
crates/observer-server         : 不动（记档：现网未回接 protect/孤儿维）
src/ · packages/ · site 代码    : 不动（npm 两包零改动零发版）
docs 四件套 + tauri.md zh/en    : 手册、进度、发版台账
```

非目标：手动清理命令、server 现网回接、体积维度、旧根治理、会话级滚动（见决策文档「未做」）。

## 3. 设计决策 ★

| # | 决策点 | 选择 | 理由 |
|---|---|---|---|
| D1 | `retention` 字段形态 | 非 `Option` + Default 空策略 | 对齐 server `ServerConfig.retention`；`is_empty()` 已有，空策略早退不扫描 |
| D2 | protect 变体位置 | storage 新增函数，原函数委托空名单 | 两 crate 共用、server 可后续 opt-in；签名不可变约束（P9 调用面） |
| D3 | 孤儿维度 | 进本期，独立字段 `orphan_max_age_days`（None = 不清，不与 `max_age_days` 联动） | P19 实证无 endedAt 是常态；显式 opt-in 守住「缺省=现状」 |
| D4 | 清扫周期 | 首跑 30s + 1h | server 10min 无必要；24h 长挂机漏扫 |
| D5 | protect 名单 | `try_state` 后 `filter(\|s\| s.active)` 取 id | stop 不清 `s.id`，不看 active 会无限期豁免已收口会话 |
| D6 | 线程护栏 | catch_unwind 包循环体 + 失败记日志 continue | `recordings_root_with` 有现成 `expect` panic 源；静默停摆最难发现 |
| D7 | 删除纪律 | Some(0)→None；validate_session_id 前置；实际成功计数 | 防呆 + 纵深 + 返回值真实（Windows 锁不计成功） |
| D8 | 版本 | storage 0.2.0 / 插件 0.6.0 双 minor；npm 不动 | additive minor（段控 D6 惯例）；TS 零面 |
| D9 | annotations | 随整目录连带删 | 会话从属数据同生命周期；保留走 export bundle |
| D10 | 手动清理命令 | 不做 | API 面最小（提案 §九.4） |

## 4. 技术方案

### 4.1 observer-storage：protect 变体 + 孤儿维 + 删除纪律

```rust
// crates/observer-storage/src/retention.rs
pub struct RetentionPolicy {
    pub max_age_days: Option<u32>,       // 既有：endedAt 超龄（未结束跳过）
    pub max_sessions: Option<u32>,       // 既有：startedAt 倒序保留 N 条
    /// 孤儿清理：无 endedAt 且 startedAt 超龄 → 可清（protect 名单仍豁免）。
    /// None = 不清孤儿（0.1.x 语义）。serde camelCase: orphanMaxAgeDays。
    pub orphan_max_age_days: Option<u32>,
}

/// 按策略清理 root 下会话，protect 名单中的 id 三条路径均跳过。
/// 相比 enforce_retention 的增量（0.2.0，均显式 opt-in / 纪律性）：
/// 1. protect 三路跳过；2. 孤儿路径随 orphan_max_age_days；
/// 3. Some(0) 一律视同 None；4. 删除前 validate_session_id，不合法跳过；
/// 5. 返回实际删除数（remove_dir_all 失败不计数）。
pub fn enforce_retention_protect(
    root: &Path,
    policy: &RetentionPolicy,
    protect: &[&str],
) -> Result<usize, String>;

/// 兼容保留：等价 protect 空名单。既有调用方策略不含新字段（serde default None）
/// 且无 protect 需求 → 正常路径行为与 0.1.x 一致（单测固化）；删除纪律三纪律点随变体生效。
pub fn enforce_retention(root: &Path, policy: &RetentionPolicy) -> Result<usize, String> {
    enforce_retention_protect(root, policy, &[])
}
```

实现要点：三条路径共用一次 `list_sessions` 扫描（meta 不可解析的残缺目录仍双向不可见——M2 边界记档，不在本期兜底，见 §7 O2）；protect 用 `HashSet<&str>`；孤儿路径判据 `endedAt 缺失 && startedAt < now - orphan_days`；单测在既有 3 用例（enforces_max_age / enforces_max_sessions / empty_policy_noop）之上新增：

1. `protect_skips_in_max_age`（已收口超龄但受保护 → 保留）
2. `protect_skips_in_max_sessions`（受保护最老会话保留，删除数正确）
3. `orphan_swept_by_started_at`（无 endedAt 且超龄 → 删）
4. `orphan_skips_protected`（同上但受保护 → 留）
5. `orphan_none_keeps_legacy_semantics`（orphan 字段 None + 无 endedAt → 留，等价 0.1.x）
6. `zero_values_treated_as_noop`（Some(0) 双维 → 0 删除）
7. `invalid_session_id_skipped`（meta.id 含 `../` / 与目录名不符 → 跳过不删不计数）
8. `delegate_empty_protect_equivalent`（原函数 = protect 空名单的回归锚）

### 4.2 插件：config 字段 + re-export + 清扫线程

```rust
// config.rs — ObserverConfig 追加（Default impl 补一行）：
/// Local 模式落盘保留策略；缺省 = 三维均 None = 不清扫（现状）。0.6.0。
#[serde(default)]
pub retention: RetentionPolicy,

// lib.rs — 模块级 re-export（宿主无需直接依赖 observer-storage）：
pub use observer_storage::RetentionPolicy;
```

setup 闭包内（`app` 为引用，spawn 前 `let app = app.clone();`；`config` 已被闭包持有，clone 进线程）：

```rust
if config.mode == Mode::Local && !config.retention.is_empty() {
    let cfg = config.clone();
    let app = app.clone();
    std::thread::spawn(move || {
        std::thread::sleep(Duration::from_secs(30)); // 避让启动 IO 高峰
        loop {
            let _ = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
                // 锁纪律：只包 id 提取，绝不跨 enforce 调用
                let protect: Vec<String> = app
                    .try_state::<std::sync::Mutex<session::Session>>()
                    .and_then(|s| s.lock().ok())
                    .filter(|s| s.active)          // D5：stop 不清 id，必须看 active
                    .and_then(|s| s.id.clone())
                    .into_iter().collect();
                let root = storage::recordings_root_with(&app, &cfg);
                match observer_storage::enforce_retention_protect(
                    &root, &cfg.retention,
                    &protect.iter().map(String::as_str).collect::<Vec<_>>(),
                ) {
                    Ok(0) => {}
                    Ok(n) => eprintln!("[observer] retention 清理 {n} 个会话: {:?}", protect_desc(&root)), // 日志含被删 id 清单
                    Err(e) => eprintln!("[observer] retention 失败: {e}"),
                }
            }));
            std::thread::sleep(Duration::from_secs(3600));
        }
    });
}
```

（骨架级伪码，实施以编译为准；`catch_unwind` 须 `AssertUnwindSafe`，panic 分支由外层 loop 自然进入下一轮。）注意：`SessionState` 是 lib.rs 私有别名，线程若独立成模块需写全 `std::sync::Mutex<session::Session>`；`recordings_root_with` 每轮重算（config 进程期固定，结果恒定，语义上对齐 P20）。

## 7. 不做什么（scope 纪律）★

- **手动清理命令** —— API 面最小（D10）；联调造数走预置目录 + 手改时间戳。
- **server 现网回接** —— 记档其对 in-ingest 会话的超量危险；opt-in 只差租户策略填字段。

- **体积维度 / 会话级滚动 / 旧根治理 / console UI** —— 见决策文档「未做」。
