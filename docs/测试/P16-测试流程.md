> P16（外部应用本地落盘）本地测试指南。覆盖 5 条验收线：插件元数据/门禁单测、console self-obs 回归、tauri-demo Remote 回归、tauri-demo Local 端到端（3.2）、落盘格式抽查；外加前序阶段回归（P5 Remote / P7 bundle 不退化）。
>
> 验证状态（2026-09-09）：场景 1 + 回归命令行项 ✅（fresh subagent 独立复核通过）；场景 4（端到端）✅ 用户实测通过（Local 录制 -> 导出 bundle -> console 导入回放全链路还原）。

## 准备：构建 + 配置


## 场景 4：tauri-demo Local 端到端（P16 核心验收，P 文档 3.2）

**目标**：外部应用本地落盘 → 导出 bundle → console 导入回放闭环。

```sh
# 终端 A：pnpm tauri dev（console，用于导入回放）
# 终端 B（关键：环境变量同时切换 Rust Mode 与 JS mode，单一来源）：
cd examples/tauri-demo && VITE_OBSERVER_MODE=local pnpm tauri dev
```

**步骤与预期**：
1. demo 主窗显示「上报到 本地落盘 · appDataDir/recordings/（Local 模式）」、状态「采集中 · 主窗口（本地落盘）」、endpoint 配置 UI 隐藏；**无需 console server 在线**。
2. 开子窗口、console.log、抛错、关子窗口（=隐藏）再开（重录）。
3. 「停止观测」→「导出 bundle（Local）」：下载 `<id>.prism-session.json`。
4. 抽查 bundle：`"format":"prism-session"`，session.source=`"tauri"`、appId=`"tauri-demo"`（来自 Rust ObserverConfig，非 JS）。
5. console 会话页「导入」该文件 → 列表出现会话，来源色点为 tauri 色（`--lane-5`）→ 回放：多窗口对齐、诊断信号流（console/error/network）、关闭=隐藏区间正确。
6. 反向门禁：同一 demo 不带环境变量（Remote 模式）调 `listSessions`/`exportSession` 应抛「仅 Local 模式可用」。

## 场景 5：落盘位置与格式抽查

**目标**：数据 own 在被观测方；元数据三态正确。

```sh
ls ~/Library/Application\ Support/<demo-identifier>/recordings/
cat ~/Library/Application\ Support/<demo-identifier>/recordings/<id>/session.json
```

**预期**：
- 目录结构 `session.json + windows.jsonl + segments/<label>#<n>.jsonl`（与 console 同构）。
- session.json：Local demo 会话含 `"source":"tauri"` + `"appId":"tauri-demo"`；场景 2 的 console 会话 `"source":"self"` 无 appId 键；停止后补 `endedAt`（覆写不丢 appId）。
