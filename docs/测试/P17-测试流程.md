# P17 测试流程

> P17（段控制上收与性能加固）本地测试指南。覆盖 5 条验收线：flush 串行化保序（SDK）、controller 手动档 API、`append_events` 脱主线程、tauri-demo 手动档门控 live run、手册量控章事实性；外加前序阶段回归（P16 Local 闭环 / P14 量控 / P5 Remote 不退化）。

## 准备：构建 + 配置

```sh
# 仓库根
pnpm install
pnpm --filter @prism-obs/observer-sdk build
pnpm --filter @prism-obs/observer-tauri build
```

console：仓库根 `pnpm tauri dev`；tauri-demo：`cd examples/tauri-demo && pnpm tauri dev`（Remote 需 console 先起）。

## 场景 1：SDK flush 串行化 + signal 注入（自动，vitest）

**目标**：在途批未完成时新事件并入下一批、批次顺序 = 发送顺序；stop 等在途批、段残留不丢；signal 段未活跃丢弃、活跃时 type:6 进流。

```sh
pnpm --filter @prism-obs/observer-sdk typecheck
pnpm --filter @prism-obs/observer-sdk test
```

**预期**：
- typecheck 0 错；vitest **3 passed; 0 failed**（segment-recorder.test.ts）。
- `pnpm --filter @prism-obs/observer-sdk build` 产 dist 正常。

## 场景 2：append_events 脱离主线程（自动 + 观察）

**目标**：async 化后 serde + 写盘不再阻塞 NSApplication 主线程；权限/注册零改动。

```sh
cd plugins/tauri-plugin-observer && cargo test && cargo check
```

**预期**：
- `cargo test` **5 passed; 0 failed**；`cargo check` 干净。
- 命令名未变 → `observer:default` 权限三件套无 diff（`git status` 应无 permissions/ 改动）。

## 场景 3：tauri-demo 手动档门控（live run）

**目标**：`gating: "manual"` 下段边界由宿主策略驱动，空闲期零落盘。

```sh
cd examples/tauri-demo
VITE_OBSERVER_GATING=manual pnpm tauri dev
```

**预期**：
1. 状态区显示「手动档 · 等待交互开段」（缺省 `VITE_OBSERVER_MODE` = Remote，console 先起）。
2. **不交互静置**：console 会话出现（会话容器已开），但应用 `appDataDir/recordings/<id>/segments/` **无新段文件**。
3. 点击页面任意处：开新段（`segments/` 出现 `<label>#<n>.jsonl`，头部为全量快照）。
4. 静置 30s：段自动收尾（文件不再增长）；再交互开 `<label>#<n+1>` 新段。
5. 空闲期点 `boom`（故意抛错）：开段且段内能看到 `type:6` error 信号（console 导入回放后信号流可见，时间轴位置正确）。
6. `exportBundle` 下载 bundle → console 会话页导入 → 回放正常、信号流齐全。

## 场景 4：缺省路径零 diff（P16 回归）

**目标**：不传新选项时逐行为等价。

```sh

pnpm tauri dev                                # Remote 常录
VITE_OBSERVER_MODE=local pnpm tauri dev       # Local 常录
```

**预期**：
- 两态行为与 P16 一致：会话广播即各窗开段、挂载兜底开段；`logThings`/`fetchThing` 信号进流；Local 态 `exportBundle` → console 导入回放全链路（P16 测试流程场景 4 同款）。
