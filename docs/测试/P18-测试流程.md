# P18 测试流程

> P18（导出 to-file 变体）本地测试指南。覆盖 4 条验收线：插件命令行为（单测）· 权限授权 · TS 包装契约 · 双端产物一致性；外加前序阶段回归（P16/P17 不退化）。

## 准备：构建 + 配置

```sh
# 插件编译 + 权限三件套重生成（build.rs COMMANDS 含新命令）
cd plugins/tauri-plugin-observer && cargo build

# 包构建（typecheck + dts）
pnpm --filter @prism-obs/observer-tauri build
```

Capabilities：宿主应用授权 `observer:default`（已含 `allow-export-session-to-file`，无需逐命令授权）。

## 场景 1：插件命令行为（Rust 单测）

**目标**：命令核心逻辑三性质——产物一致性 / 原子性 / 失败安全。

```sh
cd plugins/tauri-plugin-observer && cargo test
```

**预期**：8 passed; 0 failed，含三个 P18 新用例：
- `to_file_matches_export_ignoring_exported_at`——产物与 `build_export_bundle` 对齐（`exportedAt` 对齐后 canonical 文本逐字节一致；写入字节数 = 文件大小；`.tmp` 不残留）
- `to_file_overwrites_existing_target`——目标已存在时覆写成功且内容为新 bundle
- `to_file_errors_when_session_dir_missing`——会话目录不存在报错且不落任何文件（含 `.tmp`）

## 场景 2：权限授权（tauri-demo 实测）

**目标**：`observer:default` 授权下新命令可调；未授权窗口按 label 拒绝。

1. tauri-demo（`examples/tauri-demo`，依赖走 path → 本地 0.3.0）录一段会话
2. JS 控制台执行：

```ts
const ctrl = /* initTauri 返回的 controller */;
const bytes = await ctrl.exportSessionToFile("<sessionId>", "/tmp/demo.bundle.json");
console.log(bytes);
```

**预期**：
- 返回写入字节数；`/tmp/demo.bundle.json` 存在、`jq .format` = `"prism-session"`
- `/tmp/demo.bundle.json.tmp` 不存在（原子写消费掉）
- Remote 模式调 `exportSessionToFile` 抛 `[observer-tauri] exportSessionToFile 仅 Local 模式可用`

## 场景 3：产物可闭环（to-file → console 导入）

**目标**：to-file 产物与 `export_session` 等价、console 可导入回放。

1. 场景 2 产物拷到本机，console（`pnpm tauri dev`）会话页「导入」选该文件
2. 打开回放确认事件流可播、诊断信号面板有数据

**预期**：导入成功；回放与原会话一致（bundle 契约 version 1 零变化）。

**逐字节比对（可选）**：同会话分别走 `exportSession`（JS `JSON.stringify` 落盘）与 `exportSessionToFile`，两文件 diff 应**仅差 `exportedAt` 一行**（键序两侧同源：serde_json 无 `preserve_order`，Map = BTreeMap 排序键）。

## 场景 4：大会话导出不冻结（性能验收，bond 提案 §5 同款）

**目标**：②③热点根治——导出期间宿主窗口可交互。

1. 造大会话（全天量级，几十 MB；或用 P14 量控关闭后长时间录制）
2. 触发 `exportSessionToFile` 后立即拖拽/点击宿主窗口、DevTools Performance 录制

**预期**：窗口事件循环流畅；Performance 无归因于导出的主线程长任务（对比：改动前 `exportSession` 链路有秒级主任务）。
