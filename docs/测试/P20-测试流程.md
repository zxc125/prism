# P20 测试流程

> P20（外部落盘根自定义）本地测试指南。覆盖 4 条验收线：配置序列化兼容（单测）· 默认配置 console 零退化 · 切根落盘位置与只读命令 · 文档/版本；外加前序阶段回归（P16/P17/P18 不退化）。

## 准备：构建 + 配置

```sh
# 插件编译 + 测试（本次改动主战场）
cargo test --manifest-path plugins/tauri-plugin-observer/Cargo.toml

# console 宿主编译（path 依赖 0.4.0，13 处 recordings_root 调用点应零感知）
cargo check --manifest-path src-tauri/Cargo.toml

# 手册构建
pnpm build:site
```

无新增 capabilities/权限/命令——`observer:default` 授权面不变。

## 场景 1：配置序列化兼容（Rust 单测）

**目标**：新字段缺省 = 现状行为（P20 D5/D6 的自动化断言）。

```sh
cargo test --manifest-path plugins/tauri-plugin-observer/Cargo.toml
```

**预期**：11 passed; 0 failed（8 既有 + 3 新增）：
- `observer_config_default_uses_app_data`——`ObserverConfig::default()` → `dir_base == AppData`、`dir_name == "recordings"`
- `observer_config_serde_backward_compat`——存量宿主 JSON（`"{}"`，无新字段）反序列化得默认值，行为与 0.3.x 一致
- `dir_base_serde_camel_case`——`"resourceDir"` 序列化/反序列化往返正确；未知枚举值（`"nope"`）报错不静默吞

## 场景 2：默认配置 console 零退化

**目标**：console（不传 `dir_base`/`dir_name`，装配 `{ mode, skip_focus_prefix, ..Default::default() }`）行为与 0.3.0 逐字节一致。

1. `pnpm tauri dev` 启动 console
2. 开始录制 → 开/关一个子窗口 → 停止录制
3. 会话浏览器确认新会话出现在 `appDataDir/recordings/`，打开回放验证多窗口对齐

**预期**：
- 会话落盘位置不变（`appDataDir/recordings/<sessionId>/`）
- 录制/回放/诊断信号与改动前无差异（录制的会话目录结构 `session.json`/`windows.jsonl`/`segments/` 完全同构）

## 场景 3：切根验收（ResourceDir）

**目标**：`dir_base: ResourceDir` + `dir_name` 生效，落盘根指向安装目录（验收标准 1）。

本地快捷验证（macOS/Linux dev 环境）：

1. 临时改 `examples/tauri-demo/src-tauri/src/lib.rs` 的 `ObserverConfig` 构造（Local 分支）加 `dir_base: DirBase::ResourceDir, dir_name: "prism".into()`，`VITE_OBSERVER_MODE=local` 启动
2. 录一段会话，检查落盘位置

**预期**：
- 会话目录落在 `<resource_dir>/prism/<sessionId>/`（macOS dev 下 resource_dir = `.app` 包内或 target 目录，随构建形态；**Windows NSIS 安装布局下 = 主程序 exe 所在目录**，由 bond-sat P4 实机终验）
- `windows.jsonl`/`segments/` 结构与默认路径完全同构

验证完成后**还原 tauri-demo 临时改动**（examples 零改动是本阶段红线）。

## 场景 4：切根不迁移（决策 D6 行为确认）

**目标**：切根后旧根会话「失明」是预期行为，不是 bug。

1. 场景 3 状态下调 `listSessions()` / `exportSession()`

**预期**：
- 只列出 `<resource_dir>/prism/` 下的会话；旧 `appDataDir/recordings` 的会话**不可见但数据仍在盘上**
- 改回默认配置重启后旧会话恢复可见
- 手册 zh/en 有「切换落盘根不迁移」warning（`site/docs/tauri.md` / `site/en/docs/tauri.md` 本地落盘章节）
