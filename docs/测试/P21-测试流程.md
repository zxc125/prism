# P21 测试流程

> P21（会话列表表格化与视觉统一）本地测试指南。覆盖 4 条验收线：表格渲染与全操作 · 时长语义（bug 修复）· 字体统一 · 边界与空态；外加前序阶段回归（P10 视觉 / P16 appId / P19 回放不退化）。

## 准备：构建 + 配置

```sh
# 类型检查 + 构建（预期 0 错）
pnpm build

# 产物含 table-v2 样式（O1 验证：显式 style 导入生效）
grep -l "el-table-v2" dist/assets/*.css

# 运行时实测
pnpm tauri dev
```

无 Rust/npm/后端改动；`sessionDur` 语义变化的外溢点（TenantDetail）已同步。

## 场景 1：表格渲染与全操作

**目标**：el-table-v2「通道台账」落地，P10 会话浏览器全部操作链路不退化。

1. 打开 `#/`（Sessions 视图），核对列：来源（色点+标签）/ 时间 / 时长 / 会话 / App / 操作
2. 逐项操作：来源筛选 chip、搜索（试 id 片段与会话名）、「回放」、「⋯」下拉（编辑信息→保存→行内刷新 / 导出→Blob 下载 / 删除→确认框）、顶部「导入」
3. 窗口横向收窄

**预期**：
- 行高 40px 密度、表头 mono 疏排灰（`--ash-deep`）、无斑马纹、行 hover `--slate`、行间发丝线
- 编辑/导出/删除后列表自动刷新（refresh 触点齐全）
- 横向空间不足时**操作列固定右侧**仍可见可点
- 无 Element Plus 默认样式感（P10 场景 G 反向验收：非白底表头、非蓝色 hover、无厚面板）

## 场景 2：时长语义（核心 bug 修复）

**目标**：无 `endedAt` 会话不再渲染「now − startedAt」增长数值（实证：本机 14 会话 13 个无 endedAt，如 `1789022053209`——数据天然覆盖）。

1. 打开会话列表观察时长列；反复切换筛选/搜索/窗口焦点（触发 refresh）

**预期**：
- 无 `endedAt` 的会话时长列显**琥珀「未结束」徽标**，不显示任何时长数值；多次刷新后形态稳定（不再「一直变更」）
- 已结束会话显 mono `mm:ss` / `h:mm:ss`
- 租户详情页（Tenants → 详情）未结束会话时长显 `—`（外溢点已同步）

## 场景 3：字体统一

**目标**：`--el-font-family` 覆写生效，EP 组件与页面同栈（-apple-system 系）。

1. DevTools → Computed → Font，逐项抽查渲染字体：
   - EP 组件：编辑弹窗 el-input、el-dialog 标题、行内 el-dropdown 菜单、el-table-v2 单元格与表头、操作 ElButton、el-message toast
   - 自建：标题、正文、mono 列（时间/时长/会话 id/App）

**预期**：
- sans 处全部解析到 `-apple-system`（macOS 观感：不再是 Helvetica Neue 的字重/字距差异）；mono 处仍是 SF Mono 系
- 表头保持 mono 疏排；mono 仍严格限定时间码/ID/App/技术值列（无装饰性 mono 回潮）

## 场景 4：边界与空态

**预期**：
- 无会话 → EmptyState（图标 + 标题 + CTA「去录制」）；加载中 → SkeletonList；筛选无匹配 → 「无匹配会话」（P10 形态不变）
- appId 无值 → 该格空白；有值（如 web-demo、bond-sat 接入后）→ mono 小字
- 名称超长 → ellipsis 裁剪，hover title 显示 `name · id` 双值；named 高亮 `--bone`，裸 id `--ash-deep`

## 场景 5：批量选择与批量删除（P21 增量）

**目标**：选择列 + 批量删除链路（全选/半选/跨筛选保留/确认框/刷新清空）。

1. 勾选若干行 → 头部「删除所选 (N)」出现计数；再全选表头 checkbox（此时应呈**半选 indeterminate** → 点一次 = 当前筛选全集全选）
2. 切换筛选/搜索词再切回——已选会话保持勾选
3. 点「删除所选」→ 确认框「删除 N 个录制后无法恢复」→ 确认

**预期**：
- 全选作用于**当前筛选结果全集**（非仅可视行）；半选态正确
- 删除后列表刷新、选择集清空、按钮回到禁用态
- 确认框取消则零删除；删除计数与实际删除数一致
- 零选中时按钮禁用（opacity 0.4）
