## 场景 5：运行时清扫（手动，发版后 bond-sat 联调 / tauri-demo 实机）

**目标**：清扫线程端到端（单测不覆盖线程/睡眠/状态锁，按 P23 计划走手动）。

| # | 场景 | 步骤 | 预期 |
|---|---|---|---|
| 5.1 | 超龄 + 孤儿 + 活跃共存 | 外部应用声明 `{max_age_days: 30, max_sessions: None, orphan_max_age_days: 30}`；预置 endedAt 超 30 天会话 + 无 endedAt 且 startedAt 超 30 天会话 + 开活跃录制 | 启动 ~30s 后前两者被删、活跃会话录制全程不受影响；stderr 见 `[observer] retention 清理 N 个会话: [ids]`（含被删 id 清单） |
| 5.2 | protect 收口边界 | 5.1 后 stop_session 再等下一轮 | 已收口会话失去保护、按策略参与淘汰 |
| 5.3 | max_sessions 保护活跃 | 声明 `max_sessions: N` 且活跃会话属最老一批 | 活跃保留、其余砍到 N（protect 不占名额） |
| 5.4 | 缺省零行为 | 不传 `retention` 装插件 | 无清扫线程（console 自录回归一轮，行为同 0.5.0） |
| 5.5 | Remote 不启动 | `Mode::Remote` + 非空策略 | 无清扫线程 |
| 5.6 | panic 护栏 | 强制 root 解析失败（如锁死 appDataDir）后恢复 | 线程 panic 后下轮重试，进程不退、录制不受影响 |
| 5.7 | Windows 文件锁 | 打开会话内文件句柄后触发清扫 | 删除静默部分失败、计数如实、下轮重试（本仓 CI 无 Windows，bond-sat 实机覆盖） |
