# P11：官网与品牌（鉴 / Prism 营销站）

> 阶段路径第 11 阶段（🚧 进行中，2026-07-27 启动）。目标：建立对外品牌 identity + 营销官网，从「自录回放工具」演进到「可被发现的本地优先观测平台」。方案见 [官网（方案）.md](../品牌/官网（方案）.md)。

## 目标

P1-P10 把产品做完了（console 2.0 + 浏览器化 + 多租户），但对外是空白的：无品牌名、无官网、无开源入口。P11 补上对外这一环：

1. **品牌命名**：鉴（Jiàn）/ Prism 双轨命名，承载四条锁定决策
2. **营销官网**：独立 `site/` 工程讲述产品故事，单页滚动 12 节
3. **视觉原型**：棱镜分光主隐喻贯穿 logo / hero / section 签名元素

不是产品功能阶段，是对外品牌 + 获客门面阶段。与 console（P1-P10）正交，不污染产品代码。

## 范围

1. **品牌**：双轨命名（鉴/Prism）+ logo 概念（白光入棱镜分双光谱）+ 定位/竞品/功能叙事（方案 §1-5）
2. **工程**：`site/` 独立 pnpm workspace 成员，技术栈 Vue 3.5 + Vite 7 + Tailwind v4 + motion-v + ogl + lucide + jsrepo
3. **视觉**：继承 P10「现代科技感」token，棱镜分光为站点主隐喻；视觉执行走 `/frontend-design` 流程
4. **vue-bits 集成**：copy-paste 组件集（jsrepo registry），按需拉取 Prism/Aurora 等组件，保留 MIT+Commons Clause 版权声明

## 风险与边界

- **logo 未定稿**：当前单稿，方案 §7 决策 4 要 2-3 稿对比；hero / favicon / og 都依赖定稿。
- **i18n 缺位**：Prism 英文名 + P0 用户含国际社区，纯中文官网是错配；中英双语 vs 中文先行未定。
- **vue-bits jsrepo 拉取受阻**：`vue-bits.dev` 服务端对 jsrepo CLI 返回 SPA HTML（UA / 内容协商问题），改为 GitHub raw 直接拉源码（`DavidHDev/vue-bits/src/content/<Category>/<Comp>/<Comp>.vue`）；后续拉组件同此路径。
- **WebGL 性能**：Prism + Aurora 都是 ogl shader，hero 用 Prism 一个 WebGL 上下文；后续 section 用 Aurora 时注意同屏多上下文。
- **域名未定**：Prism 是常见词，`prism.*` 域名可能被占，可能反影响英文名形态。
- **开源准备非小事**：repo 现状 `guozhehong` 个人项目，命名 `rrweb-demo` 是 dev 名非产品名；LICENSE / README / repo 命名 / org 决策都是工作量。
- **与 console 正交**：`site/` 不进 Tauri bundle，不影响 P1-P10 产品；但品牌 token 需在 `site/` Tailwind v4 `@theme` 与 console `theme.css` 间手动同步保持一致。

> 备注：P11 是对外品牌阶段，与 P1-P10 产品演进正交。P10 风险中提到的 admin UI（增删改 key/tenant）未在本阶段，留待后续产品阶段。后续阶段（P12+）候选：开源上线（LICENSE/README/域名/部署/SEO）、admin UI、i18n--待 P11 推进后再定。
