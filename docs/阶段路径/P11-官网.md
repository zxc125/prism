## 目标

## i18n 决策（stage 9）

**决策：中英双语，zh-CN 先行，en 分阶段跟进。**

理由：

- Prism 是英文名，P0 用户含国际 Tauri / Electron 开发者与注重隐私的海外团队--纯中文官网是错配。
- 但当前品牌声音、文案、文档均为中文，强行双语会拖慢 v1 上线，且翻译质量需打磨而非机翻。
- 折中：**zh-CN 为 v1 上线语言**，**en 作为紧跟的 v1.1**，不设为上线 blocker。README 已加英文 tagline 作国际访客钩子。

实现路径（留 P12+，不属本阶段）：

- 不引 `vue-i18n` 重库；用轻量 composable（`useLang`）+ JSON 字典 + `localStorage` 持久化。
- `SiteNav` 加「中 / EN」切换；先翻 nav + hero + section 标题（导航面），正文分批跟进。
- console UI（`src/`）暂不动，仅官网 bilingual。
- `og` / `twitter` card 维持中文主卡；en 卡后续按需。
- `manifest.webmanifest` 的 `lang` 随切换更新。
