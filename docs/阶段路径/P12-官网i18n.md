# P12：官网 i18n（中英双语落地）

> 阶段路径第 12 阶段（✅ 落地，2026-07-28）。目标：把官网 `site/` 从 zh-CN 硬编码扩展为中英双语，承接 P11 stage 9「实现留 P12+」的 i18n 决策。与产品 console（P1-P10）正交，仅动 `site/`。

## 目标

P11 把官网 12 节 + nav + footer 全部落地，但文案是 zh-CN 硬编码。Prism 是英文名，P0 用户含国际 Tauri / Electron 开发者与注重隐私的海外团队——纯中文官网是错配。P12 补上双语：

1. **运行时双语**：用户点切换器实时切 zh-CN / en，全站文案响应
2. **轻量实现**：不引 `vue-i18n`，自建 `useLang` composable + JSON 字典 + `localStorage`
3. **边界清晰**：仅运行时文案双语；静态 SEO 头（og/manifest）保持中文不动（爬虫不跑 JS）

不是产品功能阶段，是官网获客门面的语言扩展阶段。

## 范围

1. **覆盖**：仅官网 `site/`，12 节 + SiteNav + Footer 全部接 `t()`，en 全量翻译一次到位
2. **不在本阶段**：console `src/` i18n（留 P12.x）、en 翻译质量深度打磨、og/manifest 静态双语变体（需构建期多语言，留后续）

## 设计决策（已拍）

| # | 决策点 | 选择 | 理由 |
|---|---|---|---|
| D1 | i18n 库 | 不引 vue-i18n，自建 useLang | 官网文案量适中（~200 条），重库不划算；与 P11 stage 9 决策一致 |
| D2 | 覆盖范围 | 仅官网 site/，全节一次到位 | P11 已定；console 文案量大且 Element Plus zhCn locale 牵动深，留 P12.x |
| D3 | en 节奏 | 全节一次到位 | 12 节文案规模可控；语言切换体验完整无残留中文 |
| D4 | og/SEO 边界 | 仅运行时双语 | 爬虫不跑 JS，og 卡以静态 HTML 为准；构建期多语言变体工作量大，留后续 |
| D5 | 状态管理 | 模块级 `useLocalStorage` 单例 + `t(path)` | 无 router/pinia，全局 ref 跨组件共享；localStorage 持久化 |
| D6 | 带 HTML 结构文案 | 拆可组合片段 key，`<br/>`/`<span>` 留模板 | 避免 v-html（安全 + 类型友好）；如 `h2_pre`/`h2_mid`/`h2_accent`/`h2_suf` |
| D7 | 技术性文案 | 保留原值不进字典（缺省回退） | 命令/`per-session`/`Tauri 2`/`observer-server`/时间码/`GET /api/user` 等不翻 |
| D8 | 切换器位置 | SiteNav `.nav-actions` | 粘性全局顶栏，滚动全程可见；mono 风格 hair 边框按钮 |
| D9 | 默认语言 | zh-CN 先行 | P11 决策；`<html lang>` 初始 `zh-CN`，localStorage 覆盖 |

## 实现

### useLang composable

[`site/src/composables/useLang.ts`](site/src/composables/useLang.ts)：

- 模块级 `currentLang = useLocalStorage<Lang>("prism:lang", "zh-CN")` —— 跨组件共享同一份状态（无 pinia）
- `t(path)` —— 点分路径嵌套取值；缺省回退 zh-CN，再缺省回退原 key（保护代码片段/命令/时间码）
- `toggle()` / `setLang(lang)` —— 切换 + 同步 `document.documentElement.lang` + 运行时 patch `document.title` / `meta[name=description]`
- 借 `@vueuse/core` 的 `useLocalStorage`（项目已装），零新依赖

### 字典

[`site/src/i18n/zh-CN.json`](site/src/i18n/zh-CN.json) + [`site/src/i18n/en.json`](site/src/i18n/en.json)，按 section 命名空间嵌套：

```
meta / nav / hero / pain / manifesto / capabilities / multiwindow /
diagnosis / loop / deploy / compare / architecture / quickstart / footer
```

- `meta` —— `title` / `description`（运行时 patch 静态头用）
- CompareSection 表格矩阵用 `compare.rows.{dim}.cells.{n}` 嵌套 key（9 行 × 7 cells）
- DeploySection meta 子数组用 `deploy.f{n}.meta.{i}` 索引 key（技术值 `Tauri 2`/`HttpBackend`/`LoginGate` 保留在组件，字典只存可翻项）

### 组件改造（13 个）

统一模式：

- 数据数组用 `computed(() => [...])` 包裹 —— 响应语言切换重新求值
- 文本字段接 `t("namespace.key")`；非文本字段（icon/accent/kind/dot/color/start/end）保留
- 模板散文接 `{{ t("...") }}`
- 带 HTML 结构的标题拆成 `h2_pre`/`h2_mid`/`h2_accent`/`h2_suf` 可组合片段，`<br/>` 和 `<span class="accent-*">` 直接写在模板里
- 技术性半英文文案保留原值不进字典（命令、`per-session`、`observer-server`、时间码、`GET /api/user`、`TypeError...` 等）

|---|---|
| [SiteNav](site/src/components/SiteNav.vue) | 加 `.lang-toggle` 切换器（中文态显「EN」、英文态显「中」）+ nav 文案接 t()；`:key` 改索引避免 label 变化失稳 |
| [HeroSection](site/src/components/HeroSection.vue) | topbar + hero copy 接 t()；h1 拆 `h1_pre`/`h1_mid`/`h1_accent`/`h1_suf` |

### og/SEO 边界（仅运行时双语）

- [`site/index.html`](site/index.html) —— `<html lang="zh-CN">` + `<title>` + og/twitter 全中文，**保持不动**（爬虫不跑 JS，og 卡以静态 HTML 为准）
- [`site/public/og-image.svg`](site/public/og-image.svg) —— 嵌中文字标，保持不动
- [`site/public/manifest.webmanifest`](site/public/manifest.webmanifest) —— `lang: "zh-CN"`，保持不动
- useLang 切换时仅 patch `document.title` + `meta[name=description]`，改善 tab 标题与搜索引擎（现代搜索引擎跑 JS）；og 卡维持中文主卡（P11 决策）

## 风险与边界

- **en 翻译质量**：当前 en 为功能完整版，措辞可再润色（技术名词保留原值，符合开发者受众预期）
- **og 卡仅中文**：英文社交分享仍呈中文卡；若需英文 og 卡，需构建期生成 en 版 `index.html` + `og-image.en.svg` + GH Pages 多入口路由（留后续）
- **console 未双语**：`src/` 仍 zh-CN + Element Plus `zhCn` locale，留 P12.x
- **`@vueuse/core` PURE 注释警告**：build 时 Rollup 对 `@vueuse/core` 的 `/* #__PURE__ */` 注释位置告警，系上游库已知噪声，不影响产物
- **localStorage 首屏闪烁**：默认 zh-CN 与 index.html 静态 `lang="zh-CN"` 一致，首屏无闪烁；若用户曾切 en，首屏先渲染中文再切 en（毫秒级，可接受；彻底解决需构建期注入 lang 到 HTML）

> 备注：P12 是 P11 i18n 决策的实现延续，与产品演进正交。后续候选：console i18n（P12.x）、og 静态双语变体、en 翻译深度打磨。P11 剩余外部动作（Gitee rename / 本地目录改名 / 自定义域名）仍待用户操作。
