## 关键陷阱（实施时发现）

**VitePress 把 `<http://…>` 自动链接语法当内部链接做死链校验**：quickstart.md 里 `浏览器打开 <http://localhost:1422>` 触发 2 处 dead link（zh/en），`vitepress build` 直接失败。解法：指向运行期本地服务的 URL 一律用行内代码 `` `http://localhost:1422` `` 而非自动链接。排查路径：build 报错输出会打印 `(!) Found dead link … in file …`。
