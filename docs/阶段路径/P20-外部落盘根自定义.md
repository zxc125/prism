# P20：外部落盘根自定义

> 阶段路径第 20 阶段。目标：`tauri-plugin-observer` Local 模式落盘根可配置（`ObserverConfig.dir_base`/`dir_name`），外部应用（bond-sat，做市交易终端）可把会话落盘指到安装目录。承接 P16（外部应用本地落盘）+ P17/P18（commands 调用面）。来源：bond-sat 2026-09-17 提案（外部仓库 docs/observer-recording/bugs/）。方案见 [外部落盘根自定义（方案）](../架构/外部落盘根自定义（方案）.md)。
>
> **进度**：✅ 落地（2026-09-17）。spec/impl/regress 全过 + subagent 独立复核零问题；发版 crates 0.4.0 已发布（`--registry crates-io --no-verify`）。bond-sat 依赖锁定回改 0.3.1 → 0.4.0 待其确认（其提案已授权以评审定稿为准）。

## 目标 ★

bond-sat 接入 Prism Local 模式，Windows 终端运维口径要求数据随安装目录（便于现场收集），而插件落盘根硬编码 `appDataDir/recordings`（`storage.rs:21-26`，console 宿主 13 处 + 插件内 4 处调用）。本阶段给 `ObserverConfig` 增加 `dir_base`（枚举 `AppData`/`ResourceDir`）+ `dir_name` 两 serde-default 可选字段，落盘根解析为 `<dir_base>/<dir_name>`，缺省值 = 现状。与主线关系：P16「外部应用本地落盘」的延伸——落盘位置从「宿主自己的 appDataDir」泛化到「宿主选定的 Tauri 标准基目录」，纯增量、不动四条锁定决策、不动 bundle 契约，console 与存量宿主行为逐字节不变。

## 范围 ★

1. **覆盖**：`DirBase` 枚举 + `dir_base`/`dir_name` 字段；`recordings_root_with` + 原 `recordings_root` 委托保留；插件 4 处调用点切 `_with`；3 个新测试；`session.rs`/`lib.rs` 注释口径；Cargo.toml **0.4.0**；site zh/en 手册（字段表含 D7 顺手修 `source`/`appId` 既有漂移）；CLAUDE.md 进度行与落盘口径；npm-crates发布.md 版本回写；发版 crates 0.4.0。
2. **不在本阶段**：历史数据迁移（不做，决策已定）；更多基目录枚举值；任意绝对路径落盘根；JS 侧任何变更（npm 两包不发版）；落盘根 UI；Windows 实机安装目录落盘验证（bond-sat 侧 P4 承担，其测试流程含路径断言）。

## 设计决策（已拍）★

| # | 决策点 | 选择 | 理由 |
|---|---|---|---|
| D1 | 注入点 | `ObserverConfig`（Rust 装配时声明） | 落盘根属部署拓扑，援引 P16 D3 同一理由 |
| D2 | API 形态 | 新增 `recordings_root_with(app, &cfg)`，原 `recordings_root(app)` 委托保留 | console 宿主实测 13 处直接调用，签名不可变更 |
| D3 | 版本 | **0.4.0 minor**（修正提案的 0.3.1 patch） | 锁定惯例「0.x minor = 兼容新增，patch 仅限公开 API 不变的执行模型变更」（P17 D6 / P18 D7 / npm-crates发布.md） |
| D4 | 解析时机 | 惰性逐次解析，不缓存进 `Session` | 调用频率极低；免 `Session::new` 签名变更；`Session.dir` 会话级缓存语义不变 |
| D5 | serde 形态 | `DirBase` camelCase（`"appData"`/`"resourceDir"`）+ `#[default] AppData`；derive 对齐 `Mode` | 与 `ObserverConfig` 既有风格一致；缺省 = 现状，`..Default::default()` 宿主零 diff |
| D6 | 迁移策略 | 不迁移；`ObserverConfig` 进程期固定；旧根数据不删、仅从 list/export 不可见 | bond-sat 无存量；console 不切根；手册 + 决策双重注明 |
| D7 | 顺手修 | site 手册字段表补齐 P16 漏掉的 `source`/`appId` 两行（zh/en 镜像） | 既有文档漂移，随本次补表一并修 |

论证细节见 [决策/外部落盘根自定义.md](../决策/外部落盘根自定义.md)；对 bond-sat 提案的三处修正（0.4.0 / `start_session` 锁外 clone / 手册字段表漂移）见方案 §2.2、§4.3。

## 关键陷阱（可选，实施时发现）

- **`start_session` 锁时序**：`recordings_root` 调用点 ：66 在锁**外**（第一段锁 :49-63 提取字段后已释放）——config 须在第一段锁内 `clone`，不可在 ：66 直接持 `&s.config`（提案原文此处失实，已核实修正）。
- **切根即「失明」**：切根后旧根会话从 `list_sessions`/`export` 消失（数据不删，仅不可见）——非 bug，属决策 D6 行为；手册与决策双重注明，回归时不得当缺陷报。
