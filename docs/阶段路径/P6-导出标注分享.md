# P6：导出 / 标注 / 分享

> 阶段路径第 6 阶段。目标：闭环到「分享 -> 复现 -> 修复」--会话可标注、可打包导出、可导入同事的会话。

## 目标

闭环到「分享 -> 复现 -> 修复」：会话可标注、可打包导出、可导入同事的会话。

## 范围

1. **标注**：回放时在时间轴打点 + 备注，存为 session 级 `annotations.jsonl`（`{ t, label, text, author }`），不混进 segment 事件流（避免污染原始数据）。
2. **元信息编辑**：重命名、备注、标签，扩展 `session.json`。
3. **导出**：会话打包成单文件（含 session.json + windows.jsonl + segments/* + annotations.jsonl），可压缩。
4. **导入/分享**：console 打开同事的会话文件，回放/诊断如本地会话。

## 改动

- [lib.rs](../../src-tauri/src/lib.rs)：新增 `export_session`/`import_session` 命令；标注落盘命令。
- [PlayerView.vue](../../src/views/PlayerView.vue)：时间轴标注打点 UI、标注列表。
- [MainView.vue](../../src/views/MainView.vue)：会话项重命名/备注/导出/导入入口。

## 验收

- 录一段、打几个标注、导出 -> 同事导入 -> 回放 + 诊断信号流 + 标注均还原。
- `pnpm build` 通过。

> 落地：标注存为 session 级 `annotations.jsonl`（`{ id, t, label, text, author, createdAt }`），与 segment 事件流分离，回放时与 signals 共享相对会话起点时间轴。console 新增命令 `list_annotations`/`save_annotations`/`update_session_meta`/`export_session`/`import_session`（[lib.rs](../../src-tauri/src/lib.rs)，新建 [annotations.rs](../../src-tauri/src/annotations.rs)）；前端 [`useAnnotations`](../../src/composables/useAnnotations.ts) 持有完整列表、增删改后立即整体覆写（标注低频，无 debounce，避免关窗丢未 flush 变更）。PlayerView 诊断栏加「信号/标注」tab + 时间轴骨白圆点标记；MainView 会话行加编辑信息/导出、顶部导入按钮 + 元信息弹窗。导出为单文件 JSON bundle（`format: prism-session`，含 session/windows/segments/annotations），零新依赖，前端 Blob 下载；导入分配新 id 重建目录、session.json 标记 `importedAt`，原 startedAt/事件 timestamp 保留使回放时间轴正确。
