# P9：多租户与运营加固

> 阶段路径第 9 阶段（规划中）。目标：从单租户走向多租户自托管 + 运营级能力。

## 目标

多租户隔离 + 存储压缩 + 保留策略，使自托管 server 可团队/多应用使用。

## 范围

1. **多租户存储**：`recordings/<tenantId>/<sessionId>/`（或 tenant 前缀），API key 映射 tenant；`session.json.appId` 与 key 授权 appId 集合校验，越权拒。
2. **配额 + 保留策略**：每租户磁盘配额；会话保留期/数量上限，过期清理。
3. **segments gzip**：落盘 + bundle + 传输 gzip（JSON 高压缩比），replay 侧透明解压。
4. **服务端 redaction**：上传 bundle 入 server 时过 redact（可选，集中管控 PII）。
5. **并发写限流**：跨租户写隔离 + 限流。

## 改动

- `observer-server`：多租户层 + 配额/保留 + gzip + 限流。
- [storage.rs](../../plugins/tauri-plugin-observer/src/storage.rs)：gzip 落盘选项。
- [SettingsView.vue](../../src/views/SettingsView.vue)：保留策略配置。

## 验收

- 多租户：不同 key 数据隔离，越权 appId 被拒。
- 配额超限上报被拒；过期会话自动清理。
- gzip 压缩比显著，回放无感。
